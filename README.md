# PredictaFlow

PredictaFlow is an AI-powered water forecasting system designed to help cities and agricultural communities understand water demand and identify potential water-related risks.

The project combines IoT sensor data, climate information, machine learning, and digital twin simulations to support proactive water management.

## Features

- **Dashboard:** Overview of the water forecasting system.
- **Water Forecasting:** Interface for exploring water-demand forecasting.
- **Digital Twin:** Simulation interface for studying water-system scenarios.
- **Weather Forecast:** Weather-related information for water planning.
- **Long-Term Prediction:** Interface for exploring longer-term forecasts.
- **AI Assistant:** An assistant integrated into the application.
- **Theme Support:** Light and dark interface themes.

## Technology Stack

- React
- TypeScript
- Vite
- React Router
- Recharts
- Lucide React
- Google GenAI SDK

## Getting Started

### Prerequisites

- Node.js and npm installed on your computer.
- Git installed if you want to clone the repository.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/gowthamsp0606/PREDICTA-FLOW-.git
   ```

2. Enter the project directory:

   ```bash
   cd PREDICTA-FLOW-
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed by Vite in your terminal.

### Production Build

To create a production build, run:
